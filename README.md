# ChatHub
ChatHub – Distributed Client-Server Chat Application
•	Developed a Java-based client-server chat application supporting multiple concurrent users through TCP sockets and multithreading.
•	Built a Swing GUI with user authentication, online-user management, real-time messaging, and file transfer.
•	Implemented a REST API for user management and authentication, with session tracking, error handling, and server audit logging.
•	Designed separate communication ports for chat, file transfer, and REST API services.
•	Tested the application with multiple users and validated login, messaging, file transfer, and server functionality.
•	Technologies: Java 17, Java Swing, TCP/IP Sockets, Multithreading, REST API, HTTP, File I/O, Eclipse IDE.
